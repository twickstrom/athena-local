# Support

Athena Local is pre-alpha.

## Community Support

Use GitHub issues for:

- reproducible bugs
- documentation problems
- feature proposals
- compatibility findings

## Not Supported Yet

The following are not supported until implementation milestones complete:

- production use
- full Athena compatibility
- full Glue compatibility
- Windows runtime support
- support for unscoped destructive remote S3 operations

## Security Issues

Do not file public issues for vulnerabilities or leaked credentials. See [SECURITY.md](SECURITY.md).
